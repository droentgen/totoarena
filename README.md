TOTO Arena คือ "สนามประลองความรู้" ส่วนตัวของนักเรียนสาธิต ม.1–ม.6 — ติวเตอร์ AI ที่ทำตัวเป็นรุ่นพี่ใจดี ไม่เฉลยตรง ๆ แต่ชวนคิดจนน้องแก้โจทย์ได้เอง แล้วตอบแทนความพยายามด้วย XP เลเวล เหรียญตรา และอันดับ หน้าตาต้อง **เท่แบบเกม แต่อ่านง่ายแบบหนังสือเรียน**

> เอกสารชุดนี้แบ่งเป็น: คู่มือแบรนด์ (หน้านี้) · แนวทางการทำงานของระบบ · โครงสร้างระบบ · ระบบเกม (Gamification) · แผนผังหน้าจอ — และดูหน้าจอตัวอย่างได้ในแท็บ Components กลุ่ม **Screens**

## 1. บุคลิกและน้ำเสียง (Content fundamentals)

**ผู้พูดหลักคือ "พี่โต้" (P'TOTO)** — AI คู่หูประจำ Arena ทำตัวเป็นรุ่นพี่ ม.ปลาย ที่เก่งแต่ไม่อวด

- เรียกตัวเองว่า **"พี่"** เรียกผู้ใช้ว่า **"น้อง"** หรือชื่อเล่น ลงท้ายสุภาพแบบเป็นกันเอง (*"นะ"*, *"เลย"*) — ไม่ใช้ "ครับ/ค่ะ" ทุกประโยค
- **ถาม ก่อนบอก** เสมอ: ✅ *"ลองสังเกตดูว่าสมการนี้มีตัวแปรอะไรบ้าง?"* ❌ *"คำตอบคือ x = 4"*
- ชมที่ **ความพยายามและวิธีคิด** ไม่ใช่ความฉลาด: ✅ *"วิธีย้ายข้างของน้องถูกแล้ว เหลือเช็กเครื่องหมายอีกนิด"* ❌ *"เก่งมาก ฉลาดสุด ๆ"*
- ตอบผิดไม่ใช่ความล้มเหลว: ใช้คำว่า **"ยังไม่ใช่"** แทน "ผิด" และตามด้วยคำใบ้เสมอ
- ศัพท์เกมเป็น **ภาษาอังกฤษตัวพิมพ์ใหญ่** (LEVEL UP, QUEST, COMBO, BOSS) ส่วนเนื้อหาวิชาเป็น **ภาษาไทยทั้งหมด** คำศัพท์เฉพาะวิชาใส่วงเล็บอังกฤษครั้งแรก เช่น *"ความเร่ง (acceleration)"*
- ตัวเลขใช้เลขอารบิก ใส่จุลภาคหลักพัน (*12,480 XP*) หน่วยไทยตามหนังสือ สสวท.
- อีโมจิ: **ไม่ใช้ในเนื้อหาวิชา** อนุญาตเฉพาะในข้อความฉลองสั้น ๆ ของพี่โต้ (สูงสุด 1 ตัว)
- ฝั่งผู้ปกครอง (Parent Console) เปลี่ยนน้ำเสียงเป็น **สุภาพ กระชับ ข้อมูลนำ** ใช้ "คุณ" และ "น้อง[ชื่อ]" ไม่มีศัพท์เกม

## 2. สี (Color)

ธีมหลักคือ **Arena (Dark)** — พื้นเขียวดำลึก ตัดด้วยเขียวเลม่อนนีออน ให้ฟีลเกม/อีสปอร์ต มีธีม **Daylight** สำหรับอ่านเนื้อหายาว ๆ กลางวันหรือพิมพ์

- พื้น 4 ชั้นไล่จากลึกไปตื้น: `bg-000` (nav) → `bg-100` (หน้า) → `bg-200` (การ์ด) → `bg-300` (hover/ช่องกรอก) ห้ามข้ามชั้นเกินหนึ่งระดับในองค์ประกอบเดียวกัน
- `lime` คือสีของ **ความก้าวหน้าและการกระทำหลัก** เท่านั้น: ปุ่มหลัก 1 ปุ่มต่อหน้าจอ, แถบ XP, ไฮไลต์ LEVEL UP — ใช้เป็นพื้นคู่กับ `on-lime` เสมอ ถ้าต้องการ lime เป็นตัวอักษรให้ใช้ `lime-text`
- `green` = ทักษะที่แข็งแรง / กราฟความก้าวหน้า, `green-deep` = บล็อก hero และแบนเนอร์ tier
- `coin` ใช้กับ T-Coins (TOTON) อย่างเดียว ห้ามใช้เป็นสีเตือน
- สถานะคำตอบ: ถูก = `lime-soft` + `lime-text` + ไอคอน ✓, ยังไม่ใช่ = `danger-soft` + `danger` + ไอคอน ✕ — **ทุกสถานะต้องมีไอคอนและคำกำกับ** ไม่พึ่งสีอย่างเดียว (ปลอดภัยสำหรับคนตาบอดสี)
- สี tier ของเหรียญตรา (`tier-bronze` … `tier-mythic`) ใช้กับเหรียญตราและป้ายอันดับเท่านั้น
- ตัวอักษรทุกคู่ผ่าน 4.5:1 ทั้งสองธีม; ขอบควบคุมใช้ `line-strong` (≥3:1); วงโฟกัสใช้ `focus` หนา 2px ทึบ offset 2px

### ผู้ใช้เลือกธีมเองได้ (มืด / สว่าง / ตามอุปกรณ์)

- ทุกคนเลือกได้ 3 ค่า: **มืด** (`dark` · Arena), **สว่าง** (`light` · Daylight), **ตามอุปกรณ์** (`system` · ตาม `prefers-color-scheme` ของ iPad/มือถือ และสลับเองเมื่ออุปกรณ์เปลี่ยน)
- ค่าเริ่มต้น: นักเรียน = **มืด**, ผู้ปกครอง = **ตามอุปกรณ์** — เปลี่ยนได้ทันทีหลังเข้าใช้ครั้งแรก
- จุดเปลี่ยนธีม: ปุ่มพระจันทร์/ดวงอาทิตย์บนแถบบนทุกหน้า (สลับเร็ว) และหน้า **ตั้งค่า › การแสดงผล** (การ์ดตัวอย่าง 3 แบบ) — ดู `ThemeToggle` และ `ScreenSettings`
- ค่าที่เลือกบันทึกกับ **โปรไฟล์ของแต่ละคน** (ใช้ได้ทุกเครื่อง) และเก็บสำรองในเครื่อง เพื่อให้หน้าเปิดมาด้วยธีมที่ถูกต้องทันที ไม่กะพริบสีผิด
- ใช้ธีมด้วยการตั้ง `data-theme="dark|light"` ที่ `<html>` เท่านั้น — **ทุกสีต้องมาจากโทเคน** ห้ามใส่สีตายตัวในคอมโพเนนต์ ไม่อย่างนั้นธีมจะเปลี่ยนไม่ครบ
- สลับแล้วเปลี่ยนสีภายใน 200ms ไม่โหลดหน้าใหม่ ไม่ทำให้คำตอบหรือข้อความที่พิมพ์ค้างหาย; เปิด "ลดการเคลื่อนไหว" แล้วเปลี่ยนทันที
- ตัวเลือกเสริม: เปิด Knowledge Hub เป็น Daylight อัตโนมัติสำหรับการอ่านยาว แม้ธีมหลักเป็นมืด

## 3. ตัวอักษร (Typography)

- **Prompt** (`--font-display`) — หัวข้อ คำทักทาย ตัวเลขเลเวล/สถิติ ชื่อ tier: เรขาคณิต หนา อ่านง่าย รองรับไทย (น้ำหนัก 600–800)
- **Anuphan** (`--font-body`) — เนื้อหาทั้งหมด: ไทยมีหัว อ่านง่าย ทันสมัย
- **JetBrains Mono** (`--font-mono`) — ตัวเลข XP เหรียญ ตัวจับเวลา คะแนน (ตัวเลขกว้างเท่ากัน ไม่กระโดดตอนนับ)
- ฟอนต์ทั้งหมดโหลดจาก Google Fonts
- ภาษาไทยต้องการ line-height สูงกว่าอังกฤษ: เนื้อหาใช้ `body` (16/26) หรือ `body-lg` (18/30) สำหรับโจทย์และแชต ห้ามบีบ line-height ต่ำกว่า 1.5 ในข้อความไทย
- หัวข้อใช้ `title` / `heading`; `display-xl` สงวนไว้สำหรับฉาก LEVEL UP และชื่อ tier
- **คำทักทายหน้าแรก** (`.ta-greet`) ตัวใหญ่ 44px หนา 800 บรรทัดแรกเป็น `ink` บรรทัดถัดไปไฮไลต์เลเวลและ tier ด้วย `lime-text` — ตามแบบที่น้องกล้าหาญเลือก
- `overline` สำหรับป้ายภาษาอังกฤษตัวพิมพ์ใหญ่เท่านั้น (ห้ามใช้กับไทย)

## 4. รูปทรง ระยะ และพื้นผิว (Visual foundations)

- **กริด 4px**: `space-1` … `space-8`; การ์ด padding `space-5`, ช่องไฟระหว่างการ์ด `space-4`, ขอบจอเดสก์ท็อป `space-7`
- **การ์ดมุมโค้ง `radius-lg`** พื้น `bg-200` ขอบบาง `line` เงา `shadow-card` เป็นพื้นผิวหลักของทุกหน้า
- **พื้นหลังลายจุด** (`.ta-dots`): จุดสี `line` ระยะ 24px บน `bg-100` ในพื้นที่หลักของหน้านักเรียน
- **การ์ดสถิติแบบไอคอน** (`.ta-istat`): ไอคอนในวงกลมมุมซ้ายบน, ป้าย `overline` ตัวพิมพ์ใหญ่มุมขวาบน, ตัวเลขใหญ่ display 800, บรรทัดย่อยสีตามความหมาย
- **ปุ่มสลับแบบแถบ** (`.ta-seg`): ตัวเลือกที่เลือกอยู่พื้น `lime`; ตารางอันดับใช้ **วงกลมลำดับ** (`.ta-rc`) ขอบสี tier gold/silver/bronze
- **มุมตัด (chamfer)** ขนาด `radius-md` สงวนไว้สำหรับเหรียญตรา ป้าย tier และโพเดียม
- **ลวดลาย = บั้งชี้ขึ้น (chevron ▲)** หมายถึง "เลื่อนขั้น" ใช้ประดับ hero และ LEVEL UP เท่านั้น ไม่ใช้เป็นพื้นหลังทั้งหน้า
- เงา: `shadow-card` สำหรับของที่ลอย; `glow-lime` เรืองแสงได้ **จุดเดียวต่อหน้าจอ** (ปุ่มหลักตอน hover หรือเควสต์ที่เพิ่งสำเร็จ)
- ไล่สีมีจุดเดียว: แถบ XP ไล่จาก `green` ไป `lime` (ซ้าย→ขวา = ใกล้เลเวลถัดไป)
- การเคลื่อนไหว: นับเลข XP ขึ้น, แถบ XP วิ่ง 400ms ease-out, LEVEL UP มีบั้งลอยขึ้น 3 ชิ้น; เคารพ `prefers-reduced-motion`
- เลย์เอาต์: ออกแบบให้ iPad (แนวนอน 1180–1366px) เป็นหลัก รองลงมาคือเดสก์ท็อป และมือถือ (แถบนำทางย้ายไปล่างจอ) — เป้ากดขั้นต่ำ 44×44px

## 5. ไอคอน (Iconography)

- ใช้ชุดไอคอน **Lucide** (เส้น 2px มุมมน) ขนาด 20px ในเนื้อหา 24px ในแถบนำทาง สีตามข้อความ (`ink` / `ink-muted`)
- ไอคอนเกมเฉพาะ (XP ▲, เหรียญ TOTON, เหรียญตรา 5 ระดับ, เปลวไฟ streak) วาดเป็น SVG รูปทรงเรขาคณิตในชุดเดียวกัน — ดูในคอมโพเนนต์ `Crest` และ `XPBar`
- **ยังไม่มีโลโก้**: ระหว่างนี้ตั้งชื่อ "TOTO Arena" ด้วย Prompt 800 โดย "TOTO" เป็น `lime-text` และ "Arena" เป็น `ink`
- พี่โต้มีอวาตาร์เป็นรูปทรงเรขาคณิต (หกเหลี่ยมตัดมุม + ตาสองขีด) ไม่ใช่การ์ตูนตัวละคร
